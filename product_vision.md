# Product Vision — «Змейка»

## 1. Идея проекта
Разработка игры «Змейка»,в которой игрок управляет змейкой на игровом поле собирает еду и набирает очки

## 2. Цель проекта
Создать простую и интересную игру, в которую будет весело играть 
## 3. Целевая аудитория
Дети и подростки,увлекающиеся играми
## 4. Основные функции
- Управление направлением движения змейки с помощью клавиш
- Перемещение змейки по игровому полю
- Увеличение длины змейки после поедания еды
- Начисление и отображение очков
- Обработка столкновений со стенами и собственным телом
- Завершение игры при столкновении
## 5. Пользовательский сценарий
1. Игрок запускает игру
2. Игрок управляет змейкой с помощью клавиш
3. Игрок направляет змейку к еде
4. После поедания еды змейка становится длиннее, а счёт увеличивается
5. При столкновении игра завершается и игрок видит итоговый результат
## 6. Критерии готовности
Проект считается готовым если:
- Игра запускается без ошибок
- Управление змейкой работает корректно
- После поедания еды увеличиваются длина змейки и счёт
- Столкновения обрабатываются правильно
- Игрок получает сообщение об окончании игры
- В репозитории есть инструкция по запуску игры
